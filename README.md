Feature Engineering on Used Car Dataset
📌 Описание проекта
Проект посвящен разработке и созданию новых признаков (Feature Engineering) для набора данных подержанных автомобилей. Основная цель — повысить предиктивную способность будущих моделей машинного обучения посредством трансформации и кодирования данных.
🛠 Выполненные задачи
Генерация новых признаков: создание дополнительных числовых и категориальных критериев на основе исходных данных (например, возраст авто, категория пробега).
Кодирование категориальных критериев: применение методик One-Hot Encoding, Label Encoding / Target Encoding для категорий.
Масштабирование данных: нормализация и стандартизация числовых признаков (StandardScaler, MinMaxScaler).
Логарифмирование и трансформации: устранение асимметрии распределений для улучшения качества моделей.
