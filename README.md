Feature Engineering on Used Car Dataset
📌 Описание проекта
Проект посвящен проектированию и сгенерированию новых признаков (Feature Engineering) для датасета подержанных автомобилей. Основная цель — повысить предиктивную способность будущих моделей машинного обучения путем трансформации и кодирования данных.
🛠 Выполненные задачи
Генерация новых признаков: создание дополнительных числовых и категориальных переменных на основе исходных данных (например, возраст авто, категории пробега).
Кодирование категориальных признаков: применение методик One-Hot Encoding, Label Encoding / Target Encoding для категорий.
Масштабирование данных: нормализация и стандартизация числовых признаков (StandardScaler, MinMaxScaler).
Логарифмирование и трансформации: устранение асимметрии распределений для улучшения качества моделей.
